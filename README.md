## How to run

Make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed, then from the project root (where the `.csproj` file lives):

```bash
dotnet build
dotnet run
```

This builds the project and runs `Program.cs`, which prints the output for each part in order to the console.

To run the BenchmarkDotNet experiment separately (it can take several minutes), run it in Release mode:

```bash
dotnet run -c Release
```

See `BENCHMARK.md` for the recorded results and analysis.
